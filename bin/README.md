# bin

Aqui ficam as DLLs compiladas de exemplo.

- `ghost_calc_payload_x86.dll` - payload 32 bits que abre calc.exe
- `ghost_calc_payload_x64.dll` - payload 64 bits que abre calc.exe

Essas DLLs sao geradas a partir de `src/payload/ghost_calc_loader.c`.
Veja `src/payload/build_instructions.md` pra compilar de novo.
